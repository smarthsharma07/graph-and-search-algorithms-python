# Graph and Search Algorithms in Python

This repository contains implementations of fundamental graph traversal and search algorithms in Python.

The goal of this repository is to practice algorithmic thinking, graph traversal techniques, and pathfinding logic through hands-on implementation.

---

## Implementations Included

| File | Description |
|---|---|
| `BFS.py` | Breadth-First Search (BFS) implementation |
| `DFS.py` | Depth-First Search (DFS) iterative implementation |
| `Dijkstra.py` | Dijkstra's Shortest Path Algorithm with path reconstruction |
